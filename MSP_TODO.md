# MSP Transition To-Do List

SupportOps Career Lab should now shift from a DCS-first support simulator into an MSP readiness cockpit for Avance Business Technologies in Dubbo. Keep DCS material as transferable experience, but make the next upgrades focus on MSP support desk habits, client communication, clean ticket notes, and reusable documentation.

## Upgrade Roadmap

### 1. MSP Mode / Avance Mode

- Add a visible MSP transition area in the app.
- Reframe the learning path around client environments, remote support, Microsoft 365 tenants, endpoint management, backups, cybersecurity alerts, documentation quality, escalation, and customer communication.
- Keep DCS examples as anonymised transferable evidence, not the main future direction.
- Add a first 30 days pathway for MSP onboarding.

### 2. Client-Safe Ticket Simulator

- Add MSP-style scenarios for Outlook access, new starters, shared mailbox permissions, OneDrive sync, printer issues, suspicious email, backup alerts, device performance, MFA lockout, and partial internet issues.
- Train scope, impact, first checks, escalation boundaries, and ticket writing.
- Use fictional client names and avoid real customer, credential, IP, endpoint, or internal procedure details.

### 3. MSP Ticket Note Coach

- Score ticket notes against MSP expectations:
  - client/user/device/service
  - business impact
  - checks completed
  - evidence gathered
  - customer communication
  - time spent
  - escalation reason
  - next action
  - no sensitive secrets copied into notes
- Show model notes after submission.
- Feed weak note areas into Due Today and Error Log.

### 4. First 30 Days At MSP Plan

- Week 1: ticketing expectations, shadowing, clean notes, escalation boundaries.
- Weeks 2-3: M365 identity/access, endpoint troubleshooting, printer/network basics, client communication templates.
- Weeks 4-6: backup/security alert triage, documentation improvement, recurring issue pattern spotting, evidence pack export.

### 5. Client Communication Trainer

- Add drills for clear client questions, investigation updates, escalation language, closure notes, and avoiding overpromising.
- Include rewrite exercises for vague updates.
- Connect communication practice to ticket-note scoring.

### 6. Knowledge Base Builder

- Generate reusable KB article templates for Outlook sign-in, MFA reset, OneDrive sync, printer first checks, new user onboarding, suspicious email triage, and backup alert first response.
- Store only generic patterns and fictional examples.

### 7. DCS-To-MSP Evidence Translator

- Map DCS work into MSP-relevant capabilities:
  - DCS account support -> identity/access support
  - Parent Portal / OurDCS support -> SaaS application support
  - classroom AV -> endpoint/peripheral troubleshooting
  - Wi-Fi/BYOD/iPad -> network/device first response
  - staff onboarding -> new user onboarding
  - ticket writing -> support documentation
  - escalation boundaries -> professional judgement
- Export a privacy-safe summary for career evidence.

## Build Discipline

- Build after each upgrade.
- Keep changes privacy-safe by default.
- Do not store real student, staff, client, credential, ticket, IP, endpoint, or confidential procedure details.
- Push completed, building slices to the deployment branch and mirror to `main` only when branch history allows it cleanly.
